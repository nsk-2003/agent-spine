# CONTEXT — Ubiquitous Language

> The shared vocabulary of this project: the terms used by developers, by domain experts, and by the code itself. When all three speak the same language, communication with the AI collapses to a few precise words instead of paragraphs, and generated code (names of files, modules, variables) reflects the domain.

This is a **durable** document — keep it true as the project's language evolves. The `grill-with-docs` skill reads it at the start of a session and updates it as new terms are agreed. Getting a term right here is not bikeshedding: every downstream artifact inherits this language.

> For a large monorepo with several bounded contexts, replace this single file with a context map and one glossary per context. For most projects, a single `CONTEXT.md` is enough.
